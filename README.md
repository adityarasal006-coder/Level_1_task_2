# Level 1 - Task 2: Core JavaScript Interactivity

This repository contains the solution for **Level 1 - Task 2** of the Web Development Internship.

## Project Features

- **Color-Changing Button**: Cycles through randomized background colors dynamically on each button click.
- **Time-Based Greeting Alert**: Detects local system time and triggers an alert message corresponding to the time of day (Morning, Afternoon, Evening, Night).
- **Two-Number Addition Calculator**: Takes two user input numbers, performs addition, handles decimals, and validates numeric input.

## Files

- index.html - Page layout and component structures
- style.css - Custom styling, layout cards, and button states
- script.js - JavaScript logic for color changing, greeting, and calculator
